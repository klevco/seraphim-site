# Разбор дня — seraphim.klevc.com

Статическая страница: мама отвечает на три вопроса про вчерашний день школьника, страница
сравнивает часы с открытыми нормами (СанПиН 1.2.3685-21, МР 2.4.0331-23 Роспотребнадзора, AASM)
и показывает, где расходится. Всё считается в браузере: запросов в сеть, форм, cookies и
хранилищ нет.

Серафим — персонаж, созданный ИИ, он не врач. Вопросы о здоровье — к педиатру.

Исходники и тесты — в рабочей папке проекта; сюда выкладываются только `index.html` и `analyze.js`.
